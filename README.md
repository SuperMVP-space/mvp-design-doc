# MVP Design Doc

Помогает выбрать, что войдёт в первую версию продукта, и собрать дизайн-док:
главный сценарий, необходимые функции, данные, границы и критерии готовности.
Работает с карточкой идеи, исследованием или свободным описанием замысла.

1. Подхватывает готовые материалы и уточняет недостающее.
2. Помогает выбрать фокус и один законченный сценарий.
3. Разделяет функции на MVP, позже и исключённые — с причинами.
4. Описывает данные, ограничения и наблюдаемые проверки результата.
5. Собирает документ и рекомендует перейти к технической спецификации.

Самостоятельный инструмент для авторов продуктов. Не требует прохождения
курса или других скиллов. Дизайн-док описывает продукт; техническая
спецификация, визуальные макеты и разработка выполняются отдельно.

## Использование

Установи папку репозитория под именем `mvp-design-doc` в каталог скиллов
своего агента. `SKILL.md` должен лежать непосредственно в этой папке.
Для обычного AI-чата передай содержимое `SKILL.md` как инструкцию.

> Используй mvp-design-doc. Вот карточка идеи и исследование альтернатив.
> Помоги выбрать состав первой версии и собрать дизайн-док.

> Используй mvp-design-doc. У меня только описание идеи: [описание].
> Помоги определить фокус MVP; неизвестное отметим отдельно.
